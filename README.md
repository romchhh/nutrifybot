# NutrifyBot

Telegram-бот для ведення раціону та аналізу КБЖУ за фото або текстовим описом страв.

## Можливості

- Реєстрація користувача та розрахунок персональної добової норми КБЖУ.
- Перегляд раціону по датах через календар.
- Додавання, перегляд та редагування записів раціону.
- Аналіз страви через OpenAI (фото/опис) з поверненням КБЖУ.
- Адмін-панель: статистика, експорт бази в Excel, розсилки, реферальні лінки.

## Детальний функціонал

### Клієнтський функціонал

- Онбординг через `/start` з перевіркою завершеності реєстрації.
- Збір параметрів профілю: ім'я, вік, стать, вага, зріст, ціль.
- Автоматичний розрахунок персональної добової норми:
  - калорії;
  - білки, жири, вуглеводи.
- Перегляд профілю та редагування даних у будь-який момент.

### Раціон і календар

- Інтерактивний календар раціону з перегортанням місяців.
- Позначення днів, у яких уже є записи по харчуванню.
- Перегляд денного зведення:
  - факт споживання КБЖУ;
  - норма КБЖУ;
  - залишок до закриття норми за всіма параметрами.
- Ручне додавання страви у форматі: `ккал білки жири вуглеводи`.
- Редагування існуючих записів за днем.

### Аналіз страви (AI)

- Аналіз по фото страви.
- Аналіз по текстовому опису страви.
- Повернення структурованого результату:
  - назва;
  - КБЖУ;
  - вага порції;
  - рівень confidence;
  - короткі нотатки.
- Додавання результату аналізу до раціону в обраний день.
- Підтримка кроків "назад" і редагування одного інтерактивного повідомлення для чистого UX.

### База знань продуктів (RAG)

- Локальна ChromaDB-колекція з базовими продуктами і КБЖУ.
- Пошук релевантних продуктів перед AI-аналізом.
- Використання знайденого контексту для більш стабільної оцінки.
- Автоініціалізація бази знань на старті бота.

### Адмін-панель

- Вхід в адмін-режим для користувачів зі списку `ADMINISTRATORS`.
- Перегляд статистики сервісу.
- Експорт даних у `.xlsx`.
- Створення і відправка розсилок.
- Робота з реферальними посиланнями та адміністраторами.

## Технології

- Python 3.11+
- [aiogram 3](https://docs.aiogram.dev/)
- SQLite
- OpenAI API
- ChromaDB (локальна база знань продуктів)

## Структура проєкту

- `main.py` — точка входу, підключення роутерів, запуск polling.
- `handlers/` — клієнтські та адмінські хендлери.
- `database_functions/` — робота з БД (`users`, `ration_entries`, адмін/лінки).
- `keyboards/` — reply/inline клавіатури.
- `states/` — FSM стани.
- `utils/` — аналіз КБЖУ, база знань, допоміжні утиліти.
- `Content/` — текстові шаблони та дані знань.

## Налаштування

Створи файл `.env` у корені проєкту та додай:

```env
TOKEN=your_telegram_bot_token
ADMINISTRATORS=[123456789]

OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=gpt-4o
OPENAI_TEMPERATURE=0.5
OPENAI_TOP_P=0.9
OPENAI_FREQUENCY_PENALTY=0.4
OPENAI_PRESENCE_PENALTY=0.1
OPENAI_MAX_COMPLETION_TOKENS=1600
OPENAI_SEED=42
```

## Встановлення і запуск

1. Створи та активуй віртуальне оточення.
2. Встанови залежності:

```bash
pip install -r requirements.txt
```

3. Запусти бота:

```bash
python3 main.py
```

Під час старту бот автоматично:

- створює потрібні таблиці в БД;
- ініціалізує базу знань продуктів.

## Корисно знати

- Основна БД: `database/data.db`.
- Якщо змінюєш тексти інтерфейсу — дивись `Content/texts.py`.
- Якщо змінюєш логіку аналізу OpenAI — дивись `utils/calories_analyzer.py`.
- Якщо змінюєш логіку раціону — дивись `handlers/client_handlers/ration_handlers.py` та `database_functions/ration_db.py`.
